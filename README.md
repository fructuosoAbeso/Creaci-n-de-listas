Creación de listas

Aplicación Android en Kotlin que muestra y gestiona un listado de películas. Incluye varias implementaciones de la misma funcionalidad usando diferentes componentes de interfaz.

Contenido del proyecto
Clase Film: modelo de datos de cada película.

FilmDataSource: lista estática con películas de prueba.

Versión básica con ArrayAdapter.
